Benchmark: mini-react vs. React 18

The same table app, written once, runs on each library. The operations come from js-framework-benchmark, the standard test for UI libraries. Times include the browser's layout work.

Libraries
Ready. A full run takes about 30 seconds with 10 runs per test.
Rendering area (the table being tested)

Each number is the median time in milliseconds, from the moment the action is dispatched until the page is updated and laid out. The fastest library for each test is marked. Numbers more than twice the fastest are shown in red.

Close other tabs and don't use the page while it runs. Results vary by 10–20% between runs, so compare big differences, not small ones.

React is loaded from cdnjs.cloudflare.com, so it needs an internet connection. Without one, only mini-react runs.
